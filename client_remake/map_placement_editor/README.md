# 地图元素布置工具

从项目根目录启动：

```powershell
node map_placement_editor/server.mjs
```

浏览器打开 `http://127.0.0.1:4180`。左侧可拖动八方向传送点和按动作数目录分类的动态怪物；静态怪物不纳入素材列表。右侧选择三国世界地图，可用左右方向键、地图选择框或按钮切换。拖动素材到地图添加元素；选择已有元素可移动、删除，传送点还可选择目标地图。滚轮或缩放按钮可缩放地图。

点击“保存布置”将地图 ID、元素类型/素材、方向、目标地图和地图图像坐标保存到本目录下的 `map_placements.json`。此文件独立于 `world_map_design/world_map.json`，不会修改现有地图关系设计。

`remake_demo` 构建时会读取此布置文件，并按 `world_map_design/world_map.json` 中的传送点连接关系生成运行时地图数据。游戏按布置坐标显示传送点和怪物；点击怪物可选中，技能会以选中怪物为目标。
