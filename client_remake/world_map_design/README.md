# 三国与中央皇城世界地图设计

## 启动

需要 Node.js 和 Python Pillow。启动本地设计器：

```powershell
python -m pip install Pillow
node server.mjs
```

默认地址为 `http://127.0.0.1:4179`。首次打开会为正在使用的地图生成小尺寸预览，缓存于系统临时目录；原地图图片不变。源图片更新后会重新生成对应预览。

## 地图布局与传送点连接

- 124 张世界地图同时显示。拖动地图卡片调整位置，单击查看地图详情，点击卡片上的“大图”按钮查看地图大图；拖动空白处平移，滚轮或工具栏缩放。
- 地图卡片上的方向标记来自 `map_placement_editor/map_placements.json` 中的传送点坐标、ID 与方向，并映射到地图缩略图的实际图像位置。修改地图元素布置后，刷新本页面即可读取最新点位。
- 单击一个未连接的传送标记进入连线状态；移动鼠标会显示从该点出发的预览线，再单击另一张地图上的目标标记完成连接。按 Esc 取消待连接。
- 连线从传送点标记的准确坐标连接到另一传送点，端点标记与线条覆盖显示在地图卡片上。不限制地图间距；连线不能穿过其他地图，传送点连线距离不能过远；拖动地图导致连线不满足条件时会暂时隐藏，保存时会报告错误。
- 每个传送点最多属于一条连接，同一对地图只能建立一条连接，且连接两端必须位于不同地图。连接点会显示为绿色；按住 Ctrl 并右键点击已连接的传送点可断开连接。可分批连线并保存，未连接数量不影响保存。
- 点击“一键排版”会依据当前已连接的传送点和出口方向调整地图位置；未连接地图置于所属区域外围，连线和区域归属保持不变。排版后检查结果，再点击“保存配置”写入 `world_map.json`。
- 点击地图查看地图物件档案。点击“保存配置”将地图位置和连接关系保存到 `world_map.json`；连线端点通过双方地图 ID 和传送点 ID 记录。地图布置文件只读，不会被此设计器修改。

## 数据文件

- `world_map.json`：124 张地图的位置、所属区域/国家、城市身份和传送点连接。
- `map_catalog.json`：全部 155 张地图预览/分类/规格、12,200 条地图物件实例的精灵、动画组、源坐标、渲染坐标及原始字段。根目录散图与地府地图保留在档案中并标记为未纳入世界。
- `object_catalog.json`：57 种地图物件精灵的视觉说明、图鉴预览、逐地图实例数量以及 1,329 张 PNG 的完整文件索引。
- `thumbnail_cache.py`：为当前世界地图生成并缓存小尺寸地图预览；使用 Pillow。
- `build_catalog.py`：从 `htol_export/images` 下的地图目录和 CSV 导出数据重建地图/物件清单及初始世界布局；运行 `python build_catalog.py` 后，再运行 `python arrange_world.py`，按地图地貌、植被与传送点关系生成自由布局和连接。
- `arrange_world.py`：只更新 `world_map.json`，读取地图档案和 `map_placement_editor/map_placements.json`，在传送点距离范围内为传送点建立方向相对优先的一对一连接；同一对地图最多连接一次，避免连线穿过其他地图，并生成非网格化布局；不会修改传送点布置源文件。
- `layout.js`：根据设计器当前连接和传送点方向计算地图排版，不会重建或修改连接。

三国布局为玄武国 45 张、邪血国 27 张、玄月国 36 张，中央皇城 16 张。海边地图 map_111/map_112/map_113 归属玄月国。三国各有两张主城地图，统一标记为“主城”并以红色边框显示；原 map_043/map_048 属于皇城。玄月国海岛主城 map_110 按海岛地图靠东南布置，与 map_013 保持分离且不直接连线。三国主城及皇城地图的分区规则见 `build_catalog.py`。

自动生成的传送点连接根据方向与相对位置推断，优先配对相反方向；连接关系是设计推断，不代表已还原游戏底层地图数据或碰撞/道路规则。页面仍可拖动地图与手动编辑连线。
