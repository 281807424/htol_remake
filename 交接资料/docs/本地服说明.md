# 浩天奇缘 J2ME 离线版（本地服务端）

> 客户端：`浩天奇缘OL-本地服.jar`（当乐 1.2.5 原包，只改了 MANIFEST 里的登录地址）
> 服务端：`work/pc_server`（纯 Java，PC 上跑）
> 最后更新：2026-10-22

## 一、快速开始

1. 双击 `work\start_pc_server.bat`
   - 控制台出现 `local server running: 127.0.0.1:28000 / 28001` 即启动成功
   - 存档在 `work\pc_save\htol_save.txt`
2. 打开 `KEmulator\KEmulator.exe` → 文件 → 载入 jar → 选 `浩天奇缘OL-本地服.jar`
   （或命令行 `KEmulator.exe jar "D:\HAOTIAN\HAOTIANnew\浩天奇缘OL-本地服.jar"`）
3. 账号密码随便填 → 登录 → 选角色 → 进入游戏

## 二、已实现的玩法

| 系统 | 说明 |
|---|---|
| 登录/选角 | 账号随意，可建 3 个角色；建号即带新手剑 + 金创药×5 |
| 主城 | 定远城，7 个 NPC（卫承 / 药品商人 / 铁匠 / 仓库管事 / 传送阵守卫 / 练功馆教头 / 收购商） |
| NPC 对话 | 点 NPC → 菜单 → 对话，卫承有城主开场白 |
| 商店 | 金币商店 / 绑金商店，可购买（实测连买扣钱正确） |
| 出售 | 收购商一键出售背包全部装备，按品质/等级计价 |
| 仓库 | 仓库管事「存入背包 / 取出仓库」，一键存取 |
| 修理 | 铁匠「修理装备」，耐久满时提示"不需要修理" |
| 传送 | 菜单→导航，13~18 张地图可选，点击即传送 |
| 战斗 | 自动索敌攻击、伤害数字、怪物反击、掉落金币/药品/装备 |
| 成长 | 经验升级、属性成长、技能按等级解锁（每 8 级 +1 招） |
| 任务 | 3 条任务链：新手试炼(5) → 初露锋芒(15) → 小有名气(30)，可提交领奖 |
| 死亡 | 回城/原地复活 |

## 三、调试控制台（开发用）

服务端另开 `127.0.0.1:28099`，一行一条命令：

| 命令 | 作用 |
|---|---|
| `shop` | 打开商店窗口 |
| `depot` | 推仓库数据 |
| `deposit` | 背包全部存入仓库 |
| `heal` | 回满血 |
| `gold 99999` | 设置金币 |
| `level 30` | 设置等级 |
| `questdone` | 当前任务进度拉满 |
| `questsubmit` | 直接完成当前任务 |
| `tp 300 300` | 改坐标 |
| `save` | 立即存档 |

PowerShell 调用示例：

```powershell
$c = New-Object Net.Sockets.TcpClient; $c.Connect('127.0.0.1',28099)
$w = New-Object IO.StreamWriter($c.GetStream()); $w.WriteLine('gold 88888'); $w.Flush()
(New-Object IO.StreamReader($c.GetStream())).ReadLine(); $c.Close()
```

## 五、协议速查（J2ME 版）

登录：`265 → 265`（byte 状态 + 2 串）、`267 → 267`（int 长度串）、`257 → 258` 服务器列表、`513/514/519/518/523/525`

游戏：`521` 地图 / `2112` 进场 / `2104` 怪物 / `2108` 攻击 / `2109` 死亡 / `2110` 定位 / `2111` 血量 /
`622` 基础属性 / `623` 详细属性 / `950` 背包(type 0/1/5) / `951` 商店 / `1220` 技能 / `1264` 武器外观

NPC：`607` 菜单（bf 格式）→ 客户端按 type 自动补内置项 → `952` 开商店 / `967` 开仓库 /
`2250` 自定义项回调 → 服务端回 `2200` 对话或 `951` / `966`+`1079` 商品操作

任务：`615` 下发 / `632` 进度（short 任务id + byte 类型 + short 目标id + byte 当前）/ `613` 移除 / `612` 提交

导航：`3006`(402) 请求列表 → `3007`（nonce 必须回显）→ `3003` 选中传送

## 六、已知限制

- **原生仓库窗口**（967 → 3004）打不通：客户端的 3004 字段全是死代码，会卡"请稍候"。
  现在的仓库是"对话式一键存取"替代方案。
- **战斗力**：J2ME 版人物面板没有这一项（只有安卓版有）。它只出现在"查看玩家"窗口里，由客户端本地计算，服务端无需处理。
- **装备改造 / 骑乘 / 称号 / 邮件 / 拍卖**：客户端 UI 存在，服务端未接。
- 只支持 240×360 键控/触摸混合操作，无真机适配。

## 七、重新构建

```powershell
# 服务端
javac -encoding UTF-8 --release 8 -d work\pc_server\classes (Get-ChildItem work\pc_server\src -Recurse -Filter *.java).FullName
# 客户端（若需重新打补丁 jar）
python work\make_local_jar.py
```
