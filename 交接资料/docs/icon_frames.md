## 探针方法（复现）

服务端 `addWeapon()` 里循环生成 30 个物品：
```
Item it = new Item(700+i, "F"+i, i /*viewId*/, 1, c.items.size());
it.type = 2;
```
换 `i` 的起始值即可扫描下一批。
