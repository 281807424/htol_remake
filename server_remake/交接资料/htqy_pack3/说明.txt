================================================================
  浩天奇缘OL 本地服务端  使用说明
================================================================

【一、运行环境】
  Windows 10/11 64 位
  Java 17 或更高（本机已装 Java 26，可直接用）
  内存 2G 以上

【二、第一次启动】
  1. 双击「启动服务端.bat」
  2. 看到下面三行就算成功：
       登录口 28000   游戏口 2890   GM口 29002
       已载入地图表 155 张
       已载入原版文案 ...
  3. 窗口不要关；关掉窗口＝停服

【三、客户端】
  本包内附「浩天奇缘OL-局域网版.apk」，已把服务器地址改成
  192.168.1.107，装到手机/模拟器上即可连本机服务端。

  ● 用 MuMu / 雷电 模拟器：直接把 apk 拖进模拟器安装
  ● 用真手机：手机要和电脑在同一个 WiFi，装 apk 后直接进游戏

  如果电脑 IP 不是 192.168.1.107：
    右键「启动服务端.bat」→ 编辑 → 把 set HOST=192.168.1.107 改成你的 IP
    客户端 apk 里的地址也要对应（这个需要另外改包）

【四、端口说明】
  28000  登录服（客户端连这个）
  2890   游戏服
  29002  GM 端口（只监听 127.0.0.1，外网连不上）

【五、常用 GM 命令】
  用任意 TCP 工具连 127.0.0.1:29002，发一行文本：
    status              看在线人数/地图/怪物数
    mypos               看所有在线玩家坐标
    allmap <编号>        把在线玩家切到指定地图
    setmapname <编号> <名字>   改地图名（写回 maps.tsv）
    auditmaps           审计全部地图落点是否可走
    act <0-8>           测试日常活动领取
    npclist             列出所有 NPC
    coords <地图名>      看该图 NPC/怪物/传送门
    killmob             清掉在线玩家身边的怪
    dungeon <编号>       把在线玩家送进副本
    guild               建帮（需建帮令+金币）

【六、数据文件（都在本目录，可直接改）】
  maps.tsv                  地图表：resId / 资源包号 / 名字 / 尺寸
  npc_spawn.tsv             NPC 坐标
  monster_spawn_original.tsv 原版刷怪点
  text_all.tsv              原版文案 1932 条（5 组）
  menu_text.tsv             菜单文案
  quests.tsv                任务
  exp_table.tsv             经验表
  world_map_nodes.tsv       国家地图节点
  door_spawn.tsv            地图传送门
  accounts.tsv              账号
  roles.tsv                 角色存档（含装备/背包/任务/日常记录）
  walk/                     154 张地图的地形寻路层（1=可走 0=不可走）

  ※ 改完 tsv 重启服务端生效；改地图名也可用 GM 的 setmapname 热改。

【七、备份】
  roles.tsv 是全部玩家存档，建议每天复制一份。

【八、故障处理】
  双击没反应      → 没装 Java，装一个 JDK/JRE 17+
  端口被占用      → 先跑「停止服务端.bat」，或改端口
  客户端连不上    → 检查手机和电脑是否同一 WiFi、Windows 防火墙是否放行 28000
  画面卡在请稍候  → 重开客户端重新登录

================================================================
【九、关于服务器地址（重要）】
  本安装包内的客户端「浩天奇缘OL-局域网版.apk」里写死的地址是
      192.168.1.107
  只连本机局域网，**不含任何公网服务器地址**。

  本目录下所有文本文件也已确认不含公网 IP。
