## 2. 逐字段比对（S→C 关键包）

### 2.1 521 `CMD_SC_SEND_RES`（地图信息）

客户端解析代码：`NetComm.CMD_SC_SEND_RES()`。

| 偏移 | 类型 | 字段 | 本次值 | 客户端用途 |
|------|------|------|--------|-----------|
| 0 | int | tileSetId | 0 | `s_TileSetId`（仅调试/兼容，可 0） |
| 4 | byte | sprCount | 12 | 本区精灵数量（≤40） |
| 5 | short×12 | sprIds | 85,86,87,88,89,90,101,109,110,107,106,105 | 进图预加载：怪物 6 个 + NPC 6 个 |
| 29 | int | zoneId | **12** | `s_ZoneId`、`s_MainChar.m_ZoneId` |
| 33 | int | mapId | 5 | `s_MapId`（<10000 非副本） |
| 37 | int | worldMapId | 0 | `s_WorldMapId` |
| 41 | byte | tileSetPal | 0 | 调色板 |
| 42 | byte | mapResId | **6** | 地图资源号：实际加载 `assets/(7+6)=13` 号地图包 |
| 43 | int | zoneFlags | 0 | 分区标记（战斗区/安全区等） |
| 47 | byte | orgId | 0 | 阵营 |
| 48 | string8 | zoneName | “定远城”（9 字节） | 右上角地名 |
| 58 | byte | transDoorCount | 0 | 传送点数量 |
| 59 | byte | hasDefaultDoor | 0 | 默认传送点 |

原始 body（60 字节）：

```
00000000 0c 550056005700580059005a0065006d006e006b006a0069
0c000000 05000000 00000000 00 06 00000000 00
09 e5ae9ae8bf9ce59f8e 00 00
```

**修复前**：服务端把 `zoneId` 写在第 0 字节（被客户端当成 tileSetId），后面多写了一个 int，
导致客户端读到的 `zoneId=0`、`zoneName=""`；`arr[18]` 的补丁只是碰巧落在 mapResId 上。
**修复后**：完全按上表顺序写出，客户端地名、分区、资源号全部正确。

> 资源号修正：`MAP_RES_IDS` 里“定远城/桃夭镇”原为 7。实测 7 对应 `assets/14` 的幽暗森林，
> 6 对应 `assets/13` 的青瓦城池。已改为 6（`map_resources.md` 的旧表整体偏移了一位，见该文件更正）。

### 2.2 2112 `CMD_SC_ENTRY_SCENE`（入场坐标）

客户端：`OnRecv_EntryScene()`：`int zoneId; ushort x; ushort y;` → 设置 `s_ZoneId`，回发 2116。

| 偏移 | 类型 | 字段 | 本次值 |
|------|------|------|--------|
| 0 | int | zoneId | **12** |
| 4 | ushort | x | 300 |
| 6 | ushort | y | 252 |

body：`0c000000 2c01 fc00`

**这是之前所有问题的根因**：旧代码这里恒发 `0`，客户端收到后把 `s_ZoneId` 覆盖成 0，
于是随后 2104（zone=12）全部被 `if (zone != s_ZoneId) return;` 丢弃，看起来就是“加 NPC 后怪没了”。

## 4. 本轮定位到的 5 个问题与修复

| # | 问题 | 现象 | 修复 |
|---|------|------|------|
| 1 | 521 字段整体错位（zone 写到 tileSetId、多一个 int） | 分区号=0、地名为空、地图不刷新 | 按 `CMD_SC_SEND_RES` 顺序重写 `buildSendRes()` |
| 2 | 2112 恒发 zone=0 | 覆盖 `s_ZoneId`，2104 全被过滤 → “怪消失” | `buildEntryScene()` 发 `MAP_ZONE_IDS[sMapIndex]` |
| 3 | 633 NPC 的 zone 写成循环变量 | 只有 1 个 NPC 能过校验 | NPC 表统一 zone=当前分区 |
| 4 | 进图前自动战斗/每 10 杀自动切图 | 选角界面就把地图从定远城推到桃夭镇 | 523 强制 `sMapIndex=5`、清空击杀数；未进游戏不发战斗包 |
| 5 | 地图资源号偏移 | 定远城显示成幽暗森林 | `MAP_RES_IDS[0]/[5]` 7→6（`assets/13` 才是城池） |

- `buildSendRes()` / `zoneSprites()` — 521
- `buildEntryScene()` — 2112
- `buildNpcs()` + `NPC_DEFS/NPC_NAMES/NPC_SPRITES` — 633
- 523/525 分支 — 进图重置与战斗门控
- `buildPlayerFull()` — 2102 zone 字段
