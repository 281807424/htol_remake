## 一、装备孔位

### 1. 孔数量（位域 3 bit，0~7 孔）

服务端 `LocalServer.writeItem()`：

```java
int uiPos = (it.equipPos >= 0 && it.equipPos <= 9) ? SLOT_UI[it.equipPos] : 0;
int packed = (it.jobReq & 3)            // bit 0~1  职业
           | ((sockets & 7) << 2)       // bit 2~4  孔数
           | ((uiPos & 31) << 5);       // bit 5~9  装备位
putInt(b, packed);
```

客户端 `work/decomp/CItem.java`（约 166 行）：

```java
p10.m_slotCount = (byte) NetComm.GetByte(v2_3, 3);  // 取 bit 2~4
```

### 2. 孔内容（紧跟总耐久/当前耐久）

服务端：

```java
for (int g = 0; g < sockets; g++) {
    putShort(b, 0);   // 0 = 空孔
}
```

客户端 `CItem.java`（188~220 行）：

```java
if (m_slotCount > 0) {
    for (int i = 0; i < m_slotCount; i++) {
        int defid = readUShort();          // 0 = 空孔，只占 2 字节
        if (defid > 0) {
            perfect = readUByte();
            quality = readUByte();
            name    = readString8();
            viewId  = readUShort();
            palId   = readUByte();
            count   = readUByte();
            for (int k = 0; k < count; k++) {
                prop[readUByte()] = readUShort();
            }
        }
    }
}
```

### 3. 当前孔数规则

```java
int sockets = it.quality >= 1 ? Math.min(it.quality, 5) : 0;
```

| 品质 | 孔数 |
|---|---|
| 白 | 0 |
| 蓝 | 1 |
| 紫 | 2 |
| 橙 | 3 |
| 青 | 4 |
| 神器 | 5 |

## 二、主界面血条

### 1. 宽度计算

`work/decomp/CGame.java` → `CGame.updateGameUi()`（约 13820 行）：

```java
s_playerHPWidth  = s_CurHp * 116 / s_MainChar.m_Properties[4];
s_playerMPWidth  = s_CurMp * 114 / s_MainChar.m_Properties[5];
s_playerExpWidth = s_Exp * 780 / s_MaxExp;

if (s_playerHPWidth > 116)  s_playerHPWidth = 116;
if (s_playerMPWidth > 114)  s_playerMPWidth = 114;
if (s_playerExpWidth > 780) s_playerExpWidth = 780;
```

`m_Properties[4]` = 最大生命，`m_Properties[5]` = 最大法力（由 622/623 设置）。

### 2. 实际绘制

`CGame.PaintHeadState()`（约 4896 行）：

```java
// 血条
s_g.setColor(0xFF0000);                     // 红
s_g.fillRect(110, 70, s_playerHPWidth, 6);

// 蓝条
s_g.setColor(0xFFFFFF);                     // 白
s_g.fillRect(108, 80, s_playerMPWidth, 6);

// 经验条
s_g.setColor(0x1FE0E1);
s_g.fillRect(7, 472, s_playerExpWidth, 6);

// 怒气条
s_g.fillRect(104, 91, s_playerAngryValWidth, 6);
```

坐标为 800×480 虚拟分辨率，运行时缩放到实际屏幕（1920×1080）。

### 3. 服务端 HP/MP 包（2111）

`LocalServer.buildHpMp()`：

```java
b.write(0x0F);          // 字段掩码：当前血/最大血/当前蓝/最大蓝
putInt(b, curHp);
putInt(b, maxHp);
putShort(b, curMp);
putShort(b, maxMp);
```

发送时机：

- 进图（525）
- 受伤/回血
- 升级
- 技能治疗/吸血
- 穿脱装备后属性刷新

客户端 `NetComm.CMD_SC_CHAR_HPMP()` → `updateCharHpMp()` 更新
`CPlayer.s_CurHp` / `s_CurMp`，下一帧重画。

### 4. 相关字段

| 字段 | 含义 |
|---|---|
| `CPlayer.s_CurHp` / `s_CurMp` | 当前血/蓝 |
| `CPlayer.s_Exp` / `s_MaxExp` | 经验/升级经验 |
| `s_MainChar.m_Properties[4]` / `[5]` | 最大血/蓝 |
| `s_playerHPWidth` / `s_playerMPWidth` / `s_playerExpWidth` | 条宽（像素） |
| `s_playerAngryValWidth` | 怒气条宽（0~100） |
| `s_MainChar.m_HpPct` | 百分比（头顶/目标血条） |

## 三、常用改动入口

| 想改什么 | 改哪里 |
|---|---|
| 血条位置/颜色/长度 | `CGame.PaintHeadState()` 的 `fillRect` 参数 |
| 血条数值来源 | 服务端 `refreshStats()`、`buildHpMp()` |
| 孔数规则 | `LocalServer.writeItem()` 里 `sockets = ...` |
| 宝石孔数据 | `writeItem()` 里空孔循环，改为写宝石 defId + 附加字段 |
